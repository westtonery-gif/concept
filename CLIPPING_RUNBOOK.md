# CLIPPING_RUNBOOK.md — как нарезать серию

> Операторская инструкция департамента нарезки. Не нормативный документ: архитектура — в
> `CLIPPING_SPEC.md` и `docs/adr/0053…0064`, приёмка — в `CLIPPING_ACCEPTANCE.md`.
>
> **Дата:** 2026-09-21.

## 0. Один раз: окружение

**`.env` никто не читает автоматически.** Все точки входа берут переменные из окружения, поэтому
перед запуском его надо выгрузить в оболочку:

```bash
set -a && source .env && set +a
```

**Значения с пробелами — только в кавычках** (`OMEMO_EPISODE_NOTION_READY_VALUE="Ready to clip"`,
`…_RUN_STATUS_PROPERTY="Run status"`). `source` исполняет `.env` как shell-код: без кавычек
`X=Run status` превращается в запуск команды `status` с временной переменной `X=Run`, и `X` в
окружении не остаётся вовсе — фабрика потом падает с «переменная не задана». А `X=Run id` молча
**выполняет** `id` (в выводе появляется `uid=…`). Если после `source` есть `command not found` или
`uid=…` — ищите незакавыченное значение. Найдено 2026-09-21 на первом живом запуске: так были
записаны четыре имени свойств Notion.

И Homebrew должен быть в `PATH` — в интерактивной оболочке он подхватывается из `~/.zprofile`, в
неинтерактивной нет:

```bash
export PATH="/opt/homebrew/bin:$PATH"
```

Проверить, что всё на месте:

```bash
ffmpeg -version | head -1 && whisper-cli --help >/dev/null && echo ok
ls "$OMEMO_WHISPER_MODEL" && ls -d "$OMEMO_EPISODE_ROOT"
```

## 1. Положить файл серии

```bash
cp ~/Downloads/s01e01.mp4 "$OMEMO_EPISODE_ROOT/"
```

Имя файла — это то, что пойдёт в колонку `Source`. Оно трактуется как **имя файла внутри папки**, а
не как путь: `../`, вложенные каталоги и абсолютные пути отклоняются (`FSE-02`).

## 2. Завести карточку на борде

База **«Эпизоды к нарезке»** (`3e264b74-a905-81cb-befb-ecee0e94c6b4`), рядом с базой ревью на
странице «Concept — нарезка».

| Колонка | Что писать |
|---|---|
| `Name` | что угодно, для человека |
| `Source` | имя файла, например `s01e01.mp4` |
| `Mode` | `scene` — резать по границам сцен; `chunk` — подряд по длине |
| `Stage` | `Ready to clip` — **это и есть команда «можно резать»** |
| `Run status`, `Run id` | не трогать, их заполняет система |

Готовность решает борд, а не агент: пока `Stage` не `Ready to clip`, запуск просто ничего не
сделает и чисто выйдет.

**Какой режим выбрать.** `chunk` — если сериал ведёт одну линию и герои на экране постоянно.
`scene` — если главных героев много и их сцены перемешаны по серии, иначе рез по длине даст две
минуты из трёх несвязанных линий.

Скопировать **id страницы** из её URL — это длинная шестнадцатеричная строка в конце.

## 3. Запустить

```bash
python demo_clips.py <id страницы эпизода>
```

Что произойдёт по порядку: борд отдаёт эпизод → файл находится в папке → ffprobe меряет, `scdet`
ищет сцены, whisper.cpp расшифровывает → строится план → каждый клип режется ffmpeg и становится
своим артефактом → QA судит каждый клип → на каждый прошедший открывается ревью и публикуется в
Notion.

Клипы появятся в `clips/` (шаблон пути — `OMEMO_CLIP_DESTINATION`).

**Индексация — самый долгий шаг.** 25-минутная серия расшифровывается минуты. Это фоновая работа
по устройству (`ADR-0053` §4), а не зависание.

## 4. Решить по каждому клипу

В базе **«Ревью Concept»** появится страница на каждый прошедший QA клип. На ней — план клипа и
**локальный путь** к файлу: Notion не проиграет файл с твоей машины, так что открывай плеером сам
(`ADR-0060` §4).

Дальше выставить `Решение`: `Одобрено` / `Отклонено` / `Доработать`. Причина — в `Причина`.

Затем **запустить ту же команду ещё раз** — она прочитает решения, одобрит что одобрено и закроет
Run, когда по всем клипам есть решение.

## 5. Что считать нормальным

- **Клип с `flagged` не одобряется никогда** — гейт закрыт правильно, это не поломка.
- **Отклонённый клип просто не едет.** Доработки у клипа нет: переделать рез значит сделать
  *другой* клип (`ADR-0059` §6).
- **Один плохой клип не валит серию.** Run падает только если сломалось производство целиком.
- **Субтитры не вжигаются** — этот ffmpeg собран без `libass` (`ADR-0063`). Тайминги при этом
  сохраняются в артефакте, так что вжигание можно включить позже правкой одного адаптера.
- Повторный запуск **безопасен**: всё закоммиченное переиспользуется, модель зря не зовётся.

## 6. Деньги

QA зовёт модель **на каждый клип**, и на вход идёт расшифровка **всей серии** — иначе критерий «нет
спойлера» нечем применять (`ADR-0056` §3). На 25-минутной серии это ~13 вызовов с немаленьким
контекстом.

**Для первого прогона возьми короткую серию.** Расшифровка и нарезка бесплатны — платится только QA.

Роль клипового QA настраивается отдельно от остальных: `OMEMO_*__CLIP_QA_AGENT_V1`. Сейчас она
повторяет настройку `qa_agent@v1`.

## 7. Что настраивается

| Переменная | Умолчание | Про что |
|---|---|---|
| `OMEMO_CLIP_CHUNK_MS` | `120000` | длина куска в `chunk`, и шаг деления слишком длинной сцены |
| `OMEMO_CLIP_MAX_MS` | `120000` | потолок, до которого `scene` сливает соседние сцены |
| `OMEMO_CLIP_PAUSE_TOLERANCE_MS` | `2000` | насколько двигать границу, чтобы не резать посреди слова |
| `OMEMO_CLIP_MAX_DURATION_MS` | `180000` | лимит платформы; клип длиннее — **провал Task**, не вердикт |
| `OMEMO_CLIP_CONTAINERS` | `mp4` | допустимые контейнеры |
| `OMEMO_CLIP_DESTINATION` | `clips/{episode_ref}-{index:02d}.mp4` | куда писать |
| `OMEMO_SCENE_THRESHOLD` | `10` | чувствительность `scdet`; **настраивается по первой реальной серии** |
| `OMEMO_WHISPER_LANGUAGE` | `auto` | сейчас `ru` |

## 8. Если что-то пошло не так

| Симптом | Причина |
|---|---|
| «is not ready to clip» | `Stage` не `Ready to clip`, или карточка не в той базе, или `Source` пуст |
| `EPISODE_SOURCE_MISSING` | файла нет в `OMEMO_EPISODE_ROOT`, либо `Source` — путь, а не имя файла |
| `FOOTAGE_INDEX_FAILED` | не найден `ffmpeg`/`whisper-cli` (проверь `PATH`) или файл не читается |
| «is not installed» | `PATH` без `/opt/homebrew/bin` |
| `ProviderModelSelectionError` | нет привязки роли — выгрузи `.env` |
| «the Whisper model is missing» | `OMEMO_WHISPER_MODEL` указывает не туда |
| сцен не найдено в режиме `scene` | план пуст, это **не ошибка**; понижай `OMEMO_SCENE_THRESHOLD` |
| клипы провалились с `CLIP_FORMAT_VIOLATION` | длиннее `OMEMO_CLIP_MAX_DURATION_MS` — подними лимит или уменьши `MAX_MS` |
