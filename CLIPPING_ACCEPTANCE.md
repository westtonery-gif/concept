# CLIPPING_ACCEPTANCE.md — Критерии приёмки департамента нарезки

> Приёмка `CLIPPING_SPEC.md` (по `ADR-0053`/`0055`/`0056`/`0058`/`0059`). Каждый критерий
> фальсифицируем: при неверной реализации соответствующий тест падает. Идентификаторы
> используются в именах тестов.
>
> **Статус:** Accepted. **Дата:** 2026-09-20.

---

## Состояние реализации

Департамент закрывается слоями, и часть из них упирается во внешнее, чего в этой среде нет.
Таблица честно говорит, что уже проверяемо, а что ждёт — чтобы «не реализовано» не читалось как
«забыто».

| Слой | Критерии | Состояние |
|---|---|---|
| `EpisodeBoard` + `IncomingEpisode` + `ClipMode` | EPB | **готово** |
| `NotionEpisodeBoard` | NEB | **готово** |
| Заглушка борда | STE | **готово** |
| `EpisodeSource` (локальный файл) | FSE | **готово**; ждёт только самого файла эпизода |
| `FootageIndex` | FIX | **готово** без вендора: ffprobe + ffmpeg `scdet` + whisper.cpp (`ADR-0064`); ждёт только файла модели |
| `plan_clips` | CLP | **готово** |
| `check_clip_format` | RND-01…04 | **готово** |
| `ClipRenderer` | FCR | **готово** на ffmpeg 9.0.2 из `homebrew-ffmpeg/ffmpeg` с `libass`; субтитры **вжигаются** (`ADR-0071`) |
| `clip_qa_agent@v1` | CQA | **готово**, Prompt v2 получает расшифровку серии (`ADR-0068`); живой вызов модели — прогон оператора |
| Оркестрация (один Run на серию) | CRN, RND-05 | **готово** на заглушках: путь собран и проверяем целиком, включая падение на каждой точке коммита |

Настоящий код адаптера (`urllib`) ходит через реальный сокет к локальному серверу, играющему
Notion, — как `NBB` и `NRD`. Ниже адаптера ничего не подменяется.

| ID | Сценарий | Ожидание |

| NEB-03 | свойство режима держит значение вне `ClipMode` | `EpisodeBoardError` — криво настроенная база, **не** молчание |

| ID | Сценарий | Ожидание |
|---|---|---|
| CLP-01 | `CHUNK`, эпизод 25 мин, `chunk_ms` 2 мин | подряд идущие интервалы, не пересекаются, покрывают эпизод, `index` с 1 |
| CLP-02 | `CHUNK`, граница попадает в середину реплики | сдвинута к ближайшей паузе в пределах допуска |
| CLP-03 | `CHUNK`, паузы рядом нет | граница остаётся на месте — правило не ломает план |
| CLP-04 | `SCENE`, короткие подряд идущие сцены | слиты, пока сумма `<= max_ms` |
| CLP-05 | `SCENE`, сцена длиннее `max_ms` | разрезана по правилу `CHUNK` |
| CLP-06 | `SCENE`, сцен нет | план пуст; это не ошибка |
| CLP-07 | эпизод короче куска | ровно один клип на весь эпизод |

| CLP-13 | `SCENE`, склейка внутри реплики | не граница; если такими были все склейки — серия одна сцена, план не пуст (`ADR-0069` §2) |

| RAU | общее аудио (`tests/test_recurring_audio.py`) | тема на разных сдвигах найдена; короткая вставка в середине — не титры; несвязанные серии не дают зон; зоны от нескольких соседей сливаются |
| FIX-11 | зоны в `LocalFootageIndex` | общее с соседом аудио у края серии → `SkipZone`; одна серия в папке — зон нет, `fpcalc` не нужен; пустой отпечаток соседа — не ошибка |
| CLP-14 | `SCENE`, рез длинной сцены посреди реплики, паузы в допуске нет | рез переносится на начало реплики; у `CHUNK` — остаётся (CLP-03) |

## 7. Оркестрация (CRN) — `tests/test_clip_production.py`

| ID | Сценарий | Ожидание |
|---|---|---|
| CRN-01 | серия с N клипами | один Run; N Task'ов, N Output'ов, N артефактов; статус Run `waiting_qa` → `waiting_human` |
| CRN-02 | у каждого клипа | своя `Evaluation` и своё `HumanReview` на **его** `artifact_id` |
| CRN-03 | один клип `flagged`, остальные `passed` | одобренные доходят до `APPROVED`; `flagged` не одобряется; Run **не** падает (`ADR-0059` §3) |
| CRN-04 | клип отклонён человеком | не шипится; цепочки `SUPERSEDED` и доработки **нет** (`ADR-0059` §6) |
| CRN-05 | все клипы получили терминальное решение | Run `COMPLETED`, каким бы ни был состав решений |
| CRN-06 | публикация ревью | адресует **каждый** артефакт, а не `pending[-1]`; двенадцать из тринадцати не теряются (`ADR-0059` §5) |
| CRN-07 | существующие `pending_review` / `publish_pending_review` / `take_review_decision` | поведение **не изменено** — приёмка Этапов 10–12 остаётся зелёной |
| CRN-08 | падение после **каждой** точки коммита | возобновление не дублирует закоммиченный Task и не пере-записывает вердикт (дисциплина `ADR-0026` §2, форма `SWR`) |
| CRN-09 | эпизод не готов / не найден | Run не создаётся, ничего не сохранено |
| CRN-10 | `ContentDirector` | **не изменён**: департамент не проходит через него (`ADR-0059` §4) |
| CRN-11 | Run завершён, одобренных нет | вызов несёт `ClipTally` (провал рендера, последние вердикты, одобрения) на **каждом** пути, включая повторный вызов терминального Run (задача 24.4) |
| CRN-13 | текст поста | черновик пишется только клипу с `passed`, один Task `post-text` на клип; ревьюер видит его в пакете; неудачный черновик не держит ревью и не повторяется; падение после любого коммита не даёт второго черновика (`ADR-0072` §2) |
| CRN-14 | правка ревьюера | при одобрении изменённый текст записан Task'ом `post-text` от `human_reviewer` и становится текстом для публикации; неизменённый не пишется повторно (`ADR-0072` §4) |
| CRN-15 | автопостинг (`ADR-0073`) | одобренный клип отправлен с текстом поста; Run не завершается, пока загрузки в пути, затем артефакты `PUBLISHED`; отказ площадки → `PUBLISH_FAILED`, без повтора, клип остаётся `APPROVED`; без текста → `NO_POST_TEXT`, ничего не отправлено; сбой публикатора ничего не меняет и повторяется; падение после любого коммита — ровно одна отправка на клип |
| UPP | `UploadPostPublisher` (`tests/test_upload_post_publisher.py`) | multipart несёт файл, профиль, площадки, заголовок, описание, приватность, `async_upload`, наш `request_id` и `Idempotency-Key`; подпись TikTok/Instagram = заголовок + описание; статусы отображаются, неизвестный — отказ; ключ не попадает в сообщения; настройки из окружения, приватность обязательна |
| CRN-12 | индекс серии | записан в Run как Output Task'а `index-footage` до клипов; QA каждого клипа получает расшифровку из него; возобновление на `WAITING_QA` оценивает без повторной индексации; Run без индекса — ошибка QA, вердикта нет (`ADR-0068` §2) |

## 8. Настоящий рендерер и источник (FCR / FSE) — `tests/test_ffmpeg_clip_renderer.py`

Тесты рендерера режут **настоящее** видео, которое ffmpeg сам и генерирует, и читают результат
через ffprobe. Ничего не подменяется: неверная командная строка означала бы, что файла нет или он
измеряется не так. Там, где ffmpeg не установлен, они **скипаются** — для машины, которая не может
их выполнить, это честный ответ, а не «прошло».

| ID | Сценарий | Ожидание |
|---|---|---|
| FCR-01 | вырезать 2–5 с из десятисекундного эпизода | файл существует и непуст; длительность ≈ 3 с, размер кадра из источника, контейнер `mp4` |
| FCR-01 | запросить кусок за пределами эпизода | длительность **меньше** запрошенной: измерения берутся из файла, а не из запроса |
| FCR-02 | `captions` переданы | **вжжены** (`ADR-0071`): реплика видна в кадре в свой интервал и не видна вне его; без `captions` кадр чистый; текст не может внедрить разметку ASS |
| FCR-03 | каталога назначения нет | создан |
| FCR-04 | файла эпизода нет | `ClipRendererError` |
| FCR-05 | бинарника нет | `ClipRendererError`, названо имя |
| FCR-06 | источник не видео | `ClipRendererError` — настоящий отказ настоящего инструмента, а не падение |
| FCR-07 | таймаут | `ClipRendererError` |
| FCR-09 | холст (`ADR-0075`) | размер файла — холст; картинка целиком, по центру; сверху и снизу чёрное; стороны холста — положительные и чётные |
| FCR-08 | ffmpeg без `libass` | `ClipRendererError`, называющий `libass` — клип без субтитров молча не выходит (`ADR-0071` §3) |
| FSE-01 | файл в корне | `LocatedEpisode` с полным путём |
| FSE-02 | `..`, `/etc/passwd`, `sub/dir.mp4`, пустая строка, несуществующий | `None` — борд, который правит кто-то другой, не выходит за свою папку |
| FSE-03 | каталог вместо файла | `None` |
| FSE-04 | `OMEMO_EPISODE_ROOT` | обязателен; отказ называет переменную |

## 9. Сборка (CMP) — `tests/test_clip_composition.py`

Только build-time: ничего не зовёт модель, не ходит в сеть и не запускает ffmpeg. Смысл в том,
чтобы неверная настройка падала **до** того, как что-либо начнётся, и называла себя.

| ID | Сценарий | Ожидание |
|---|---|---|
| CMP-01 | настройки без переменных | рабочие умолчания: куски по 2 мин, потолок 2 мин, допуск 2 с, лимит платформы 3 мин, контейнер `mp4` |
| CMP-01 | каждая переменная задана | переопределяет умолчание, включая список контейнеров и шаблон пути |
| CMP-02 | ноль, отрицательное, не число, пустой список контейнеров | `CompositionError` / `ValueError`, названа переменная |
| CMP-02 | умолчания против правила `ADR-0040` | у длительностей умолчания **есть**, у пути к модели — **нет**: имя чужой колонки угадывать нельзя, а длину клипа можно с чего-то начать |
| CMP-03 | нет `OMEMO_EPISODE_ROOT` / `OMEMO_WHISPER_MODEL` | отказ называет переменную |
| CMP-04 | рендерер | конфигурации пока не требует |
| CMP-05 | полное окружение | путь собирается; `has_desk` отражает наличие площадки |
| CMP-06 | убрана одна переменная | сборка падает целиком, названа именно она — ничего полусобранного до Run не доходит |
| CMP-07 | собранные части | настоящие реализации, не заглушки |
