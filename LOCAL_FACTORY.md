# Локальная фабрика → YouTube Shorts

Точка входа: `factory.py`. Notion для неё не нужен.
Поддерживается прямая публикация в YouTube. Это не команда публикации Instagram Reels.

## Один раз на компьютере

Из корня репозитория, Python 3.11+:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[youtube]'
```

На Windows активация: `.venv\Scripts\Activate.ps1` в PowerShell.

Установите `ffmpeg` с libass (фильтр `subtitles`), `ffprobe`, `whisper-cli` из whisper.cpp
и `fpcalc` из Chromaprint. Все четыре команды должны быть доступны в PATH.
Скачайте совместимую с whisper.cpp модель, например `ggml-small.bin`.
Эти программы и модель не входят в Python-пакет и не скачиваются автоматически.

Для YouTube подготовьте Desktop OAuth JSON: включите YouTube Data API v3,
настройте OAuth-приложение и добавьте свой аккаунт в тестировщики, если используется Testing.
Подробности — [YOUTUBE_SETUP.md](YOUTUBE_SETUP.md).
Доступ разрешает владелец канала в браузере; логин и пароль в команду не передаются.
Отдельно нужен API-ключ OpenAI или Anthropic для выбора моментов, QA и текста.

## Первый запуск

```sh
python factory.py '/полный/путь/серия.mp4' \
  --profile cartoons \
  --client-json '/полный/путь/client_secret.json' \
  --channel @мойканал \
  --whisper-model '/полный/путь/ggml-small.bin'
```

Если настройки отсутствуют, команда спросит путь к модели, предложит выбрать GPT/Claude
и ввести ключ скрыто, затем запросит OAuth JSON и имя канала и откроет Google в браузере.
Можно сразу запустить `python factory.py '/путь/серия.mp4' --profile cartoons`
и ответить на эти вопросы. Для ввода нужен обычный интерактивный терминал.

Сохранение: общие настройки в `.env`, подключение канала в `.env.youtube-cartoons`,
токен и квитанции в `.omemo/`. Они исключены из Git. Каждый канал использует свой профиль.
При переносе репозитория на другой компьютер заново выполните подключение, поскольку
сохранённые пути локальные. Не публикуйте токены и OAuth JSON в Git.

## Следующие серии

```sh
python factory.py '/полный/путь/следующая-серия.mp4' --profile cartoons
```

Последовательность:

1. Проверка инструментов и настроек.
2. Расшифровка всей серии и анализ сцен.
3. Выбор моделью до трёх моментов длиной 25–60 секунд до обработки скорости.
4. Вертикальный монтаж, субтитры, обработка видео, QA.
5. Название и описание YouTube в TXT рядом с прошедшими QA клипами.
6. Для каждого готового клипа — путь к видео, настройка аудитории `yes/no` (для детей),
   затем точный текст, ID канала и публичная видимость.
7. Откройте и посмотрите MP4, проверьте TXT. Введите ровно `publish`, чтобы загрузить
   показанный клип. Любой другой ответ пропускает его. Отдельное одобрение на каждый клип.

Перед показом текста TXT можно отредактировать. Изменение MP4 или TXT после показа
делает одобрение недействительным. При ошибке загрузки команда останавливается.
Полученная ссылка означает принятую загрузку; обработку и ограничения проверяйте в Studio.

Результаты: папка `outputs/<имя-серии>-<идентификатор>/` рядом с исходной серией.
Суффикс отделяет разные файлы и настройки. Есть MP4, TXT и отчёты обработки.
По умолчанию локальный профиль использует 720×1280 и размытый фон; значения
`OMEMO_CLIP_*` из существующего окружения могут изменять оформление.

```sh
# Только подготовить, не подключая канал и не предлагая публикацию:
python factory.py '/путь/серия.mp4' --draft-only

# Число моментов и другое место сохранения:
python factory.py '/путь/серия.mp4' --profile cartoons --count 5 --output '/путь/outputs'
```

Повтор команды с тем же видео и настройками продолжает сохранённый прогон.
Уже загруженные клипы пропускаются по квитанциям. Не удаляйте `.omemo/` для «повторной попытки»:
при неопределённом исходе загрузки сначала проверьте YouTube Studio.
На другом компьютере квитанций нет — для продолжения тех же публикаций перенесите их отдельно.

Подготовка хранится в `.omemo/local-factory.sqlite3`. Локальное согласование и загрузка
используют `post_youtube.py` и его квитанции; решения не записываются в Notion,
а статус производственного Run может оставаться `waiting_human` после ручной публикации.
Отсутствие прошедших QA клипов с TXT завершает команду с ошибкой без публикации.
Whisper локальный; запросы к выбранной языковой модели платные. Проверяйте субтитры человеком.

## Проверено

Прямая загрузка YouTube проверена реальными публикациями на двух каналах.
Для новой команды есть проверки без внешних сервисов: подключение локального источника
без Notion, обязательное одобрение, изменение текста после предпросмотра, аудитория,
режим черновиков и разделение прогонов при изменении исходника.
Полный новый запуск с реальными GPT/Claude и OAuth на чистом компьютере ещё не проверен.
