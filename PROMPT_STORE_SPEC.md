## 1. Назначение и граница

Production-текст Prompt хранится как версионируемые данные вне Python-модулей ролей. Встроенное
хранилище — отслеживаемый Git пакетный TOML-ресурс `prompts/catalogue.toml`. Оно содержит активный
Prompt каждой роли: `prompt_id`, положительную целую `version`, `schema_ref`, `system` и
`user_template`.

Хранилище не является новой доменной сущностью и не меняет `Prompt`: загрузчик только материализует
неизменяемые `Prompt` из внешних данных. Выбор активной версии, история и runtime-редактирование не
входят в этот срез; в каталоге допустима ровно одна активная запись на `prompt_id`.

## 2. Владение и загрузка

- Каталог читает только Composition Root на build-time.
- `Agent`, `TaskExecutor`, `ContentDirector`, Workflow и домен не читают файлы и не знают формат.
- Production-вызовы Composition Root, которым не передана явная mapping Prompt, читают встроенный
  каталог. Явная mapping остаётся поддержанным входом для тестов и внешнего встраивания.
- Один верхнеуровневый вызов сборки читает каталог один раз и использует один снимок данных для
  executor/schema wiring.
- Загрузчик не кеширует каталог и не создаёт изменяемого глобального состояния.

## 3. Формат каталога

Корень TOML содержит только непустой массив таблиц `prompts`. Каждая таблица содержит ровно поля:

- `prompt_id: str` — непустой логический идентификатор;
- `version: int` — `>= 1`, `bool` недопустим;
- `schema_ref: str` — непустая опаковая ссылка на Schema;
- `system: str` — непустой System Prompt;
- `user_template: str` — непустой User Prompt template.

Порядок записей не задаёт execution-порядок. Результат загрузки — новая mapping
`prompt_id -> Prompt`; порядок входного TOML не является частью контракта.

## 4. Fail-closed инварианты

Сборка завершается `CompositionError` до исполнения Task, если ресурс нельзя прочитать, TOML
повреждён, корневая форма или набор полей неверны, значение имеет неверный тип/пусто, версия меньше
единицы либо `prompt_id` повторяется. Частично загруженный каталог не возвращается.

Текст передаётся в `Prompt` без нормализации или скрытого изменения. Изменение текста требует
явного увеличения `version`; неизменённый перенос текущего текста из Python в каталог сохраняет
версию 1.

## 5. Не-цели

- удалённый Prompt CMS, network/storage Adapter или hot reload;
- выбор «последней» версии, rollout/A-B activation и история версий в runtime;
- интерполяция окружения, секретов или других файлов;
- изменение доменных контрактов `Agent`, `Prompt`, Schema, Run или orchestration.
