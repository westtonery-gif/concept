# GENERATION_ACCEPTANCE.md — Критерии приёмки генерационного департамента

> Приёмка `GENERATION_SPEC.md` (по `ADR-0066`/`0067`). Каждый критерий фальсифицируем:
> при неверной реализации соответствующий тест падает. Идентификаторы используются в именах тестов.
>
> **Статус:** Accepted — частично (§1–§6; остальное — с 23.3–23.6). **Дата:** 2026-09-21.

---

## Состояние реализации

| Слой | Критерии | Состояние |
|---|---|---|
| Порты `ImageGenerator` / `VideoGenerator` | GNP | **готово** |
| Замеры медиа (stdlib) | MED | **готово**; MED-05 читает MP4 настоящего ffmpeg, если он есть |
| `GeminiImageGenerator` | GIG | **готово** против локального сервера. **Против настоящего Google не проверено** — ждёт ключа (LIV) |
| `HiggsfieldVideoGenerator` | HVG | **готово** против локального сервера. **Против настоящего Higgsfield не проверено** — ждёт ключей и кредитов (LIV) |
| Озвучка: порт `SpeechSynthesizer` + `KokoroSpeechSynthesizer` | SPP, KOK | **готово** против подменяемого движка; **LIV-03** слушает настоящую модель; один прогон на настоящей модели 2026-10-06: слова в пределах ~250 мс от whisper.cpp |
| Живая генерация | LIV | **написано, не запускалось**: `OMEMO_LIVE_GENERATION=1` + ключи + фото. Тратит деньги |
| QA, борд, Run, оркестрация | — | не начато (23.3–23.7) |

Локальные серверы доказывают **нашу** сторону провода. Что вендоры действительно присылают то, что
написано в их документации, доказывает только LIV — до его первого прогона департамент **не**
считается проверенным на настоящих API.

## 5. Higgsfield (HVG) — `tests/test_higgsfield_video_generator.py`

| ID | Сценарий | Ожидание |
|---|---|---|
| HVG-01 | `submit` | два тикета загрузки с типом по сигнатуре, два `PUT` **без** авторизации с `upload_headers`, один `POST /<model>` с `image_url`/`last_image_url`/`duration`/`sound`; `VideoJob(request_id)` |
| HVG-02 | длительность 2 или 16 | ошибка до любого запроса |
| HVG-03 | 401 / 403 / нет `request_id` / `request_id` не UUID | ошибка с объяснением кода, генерация отправлена **ровно один раз**, ключей в сообщении нет |
| HVG-04 | `queued`, `in_progress`, `failed`, `canceled`, `nsfw` | `PENDING`/`PENDING`/`FAILED`/`FAILED`/`REJECTED`; ничего не скачано и не записано |
| HVG-05 | `completed` дважды | скачано без авторизации, измерено, записано атомарно (без временных файлов); повтор даёт тот же результат |
| HVG-06 | скачанное не MP4 | ошибка без URL, файл не записан |
| HVG-07 | `completed` без видео, URL не http(s), неизвестный статус | ошибка |
| HVG-08 | `job_id` не UUID | ошибка без единого запроса |
| HVG-09 | неизвестная задача | ошибка с HTTP 404 |
| HVG-10 | настройки из окружения | четыре обязательных; модель без конечного кадра (Turbo) и звук не `on`/`off` отвергнуты; ключи не в `repr` |

## 6. Живая генерация (LIV) — `tests/test_live_generation.py`

Запускается только при `OMEMO_LIVE_GENERATION=1` и заданных переменных; иначе **пропуск с
причиной**. Тратит деньги оператора.

| ID | Сценарий | Ожидание |
|---|---|---|
| LIV-01 | настоящий Gemini на настоящем фото | кадр записан, соотношение сторон — фото (±3%) |
| LIV-02 | весь конвейер из двух вызовов | кадр → `submit` → опрос с backoff до 15 мин → `COMPLETED`, MP4 4–6,5 с для запрошенных 5 с |

## 7. Озвучка (SPP, KOK) — `tests/test_speech_synthesizer.py`, `tests/test_kokoro_speech_synthesizer.py`

| ID | Сценарий | Ожидание |
|---|---|---|
| SPP-01 | пустой `text`/`voice`/`destination`; `speed` 0, отрицательная, `bool` | `ValueError` |
| SPP-02 | `SpokenWord`: пустой текст, `end <= start`, `start < 0` | `ValueError` |
| SPP-03 | `SynthesizedSpeech`: неположительные замеры, пустые слова, слова не по порядку, пересекаются или выходят за `duration_ms` | `ValueError` |
| ADB-06 | `speech_synthesizer` в списке модулей `adapters/` | импортируется сам по себе, только stdlib + `domain.*` |
| KOK-01 | успешный синтез подменным движком | WAV записан; `duration_ms` и `sample_rate` **из файла**, а не из запроса |
| KOK-02 | слова | все слова текста по порядку, с пунктуацией; границы возрастают, не пересекаются, внутри файла; первое слово начинается у начала звука, последнее заканчивается у его конца; более длинное слово получает более длинный отрезок |
| KOK-03 | голос `name` и смесь `a:0.6+b:0.4` | движку приходит нормированная смесь; веса `0.6+0.4` и `3+2` равны |
| KOK-04 | пустое имя, повтор, вес 0 / отрицательный / нечисловой | `SpeechSynthesizerError`, движок **не** вызван |
| KOK-05 | префикс голоса не `af`/`am`/`bf`/`bm` | `SpeechSynthesizerError` до движка |
| KOK-06 | сбой движка, пустое аудио, полная тишина | `SpeechSynthesizerError`; файл не записан, прежний не тронут |
| KOK-07 | повтор того же запроса | тот же файл перезаписан, временных файлов не осталось |
| KOK-08 | настройки из окружения | обе переменные обязательны, недостающая названа; несуществующий файл назван |
| KOK-09 | `composition.build_speech_synthesizer` | собирается при двух существующих файлах без загрузки модели; без переменных — `CompositionError` с названиями |
| LIV-03 | настоящая модель при заданных `OMEMO_KOKORO_*` | синтез реплики, непустой WAV; пропуск с причиной без модели или пакета |
