# STAGE11_ACCEPTANCE.md — Acceptance Criteria (ROADMAP Этап 11, интеграция с n8n)

**Версия:** 1.0
**Статус:** Принят
**Дата:** 2026-09-17
**Префикс тестов:** `S11A`
**Решение:** `docs/adr/0050-stage-11-acceptance.md`

Настоящий `ProductionService` (`build_production_service`) на `127.0.0.1` поверх производственного
пути `STAGE10_ACCEPTANCE.md` (встроенные Prompt трёх ролей, Skill и Tool Rin, настоящие
`AnthropicLLMClient` с подменённым транспортом, `SqliteRunStore` под `BriefStatusReporter`,
`InMemoryBriefBoard`, площадка в роли Google Doc), собранного как `BriefProduction` с
`build_run_index`. Каждый запрос **строится из закоммиченного воркфлоу n8n**: метод, маршрут и
параметры тела его узла HTTP Request, `={{ $json.id }}` — из элемента в форме упрощённого вывода
Notion Trigger, учётка Header Auth — токен. После каждого запроса тест ждёт, пока исполнитель
освободится.

Definition of Done Этапа 11 (ROADMAP.md): (1) создание брифа в Notion автоматически запускает `Run`
через n8n; (2) бизнес-логика — в Content Director, n8n — только транспорт и триггеры.

## Acceptance

| ID | Критерий |
|---|---|
| S11A-01 | Готовая страница обновлена → запрос `brief-ready` → `202 queued: true`; Run `run-notion-<id>` в `waiting_human`, вход первой Task — текст брифа; на доске `queued, running, waiting_qa, waiting_human`; ревью опубликовано, на доске ссылка на него. |
| S11A-02 | Неготовая и неизвестная страница → `202`; ничего не сохранено, моделей и записей на доску нет. |
| S11A-03 | После производства n8n присылает ту же страницу ещё трижды (правки ядра будят опрос) → моделей нет, записей на доску нет, снимок не изменён. |
| S11A-04 | На площадке «одобрено» → запрос `review-sweep` → `202 {"waiting": [id], "queued": [id]}`; Run `completed` без моделей; на доске добавлен `completed`; следующий sweep — `waiting: []`. |
| S11A-05 | QA `flagged`, на площадке «доработать» → sweep → вызваны только Leo и QA; версия 2 ждёт человека; на доске вторая ссылка. |
| S11A-06 | Учётка n8n с неверным токеном → `401` на оба воркфлоу; ничего не поставлено и не вызвано. |
| S11A-07 | Доска падает при чтении брифа → задача падает (`ERROR` в логе), сервис отвечает дальше; следующая страница производится. |
| S11A-08 | Сервис остановлен с Run в `waiting_human`; новый сервис над тем же файлом; решение на площадке → sweep нового сервиса завершает Run. |
| S11A-09 | Воркфлоу, чьё тело использует неизвестное выражение, не рендерится (тест падает, а не угадывает). |

## Вне критериев

Живой n8n и Notion — проверка оператора (`n8n/README.md`); форма файлов — `N8N`; HTTP-граница
по отдельности — `SVC` (`PRODUCTION_SERVICE_ACCEPTANCE.md`).

## Quality gate

Все S11A-тесты и полный gate (`ruff check`, `ruff format --check`, `mypy --strict`, `pytest`) должны
быть зелёными до коммита.
